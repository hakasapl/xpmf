# xpmf
Extended Projected Materials Framework for The Elder Scrolls V: Skyrim

Profiles are JSON files in `Data/SKSE/Plugins/XPMF/`; every setting is described in [schema/profile.schema.json](schema/profile.schema.json), which a `"$schema"` key in a profile lets an editor validate against.

Supports SE, AE and VR. On VR, requires "VR Address Library for SKSEVR" 0.266.0 or later.
